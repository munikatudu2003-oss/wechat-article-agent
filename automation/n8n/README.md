# n8n workflow templates

These workflow templates orchestrate the local HTTP API exposed by `wechat-article-agent`.

## Files

- `workflows/01-generate-draft.json`
- `workflows/02-create-and-submit.json`
- `workflows/03-sync-status.json`

For Coze-driven generation, use the local API endpoint `/ingest-draft` after Coze returns structured content.

## Import

1. Open n8n.
2. Import each JSON file as a workflow.
3. Set the workflow timezone to `Asia/Shanghai`.
4. Publish the workflow after testing.

## Manual runs

These workflows use `Schedule Trigger` for automatic runs.
For manual runs, use n8n's built-in `Execute Workflow` button in the editor.

## Required environment variables in n8n

- `WECHAT_AGENT_API_BASE_URL`
  - Example: `http://127.0.0.1:8088`
- `WECHAT_AGENT_SOURCE_MODE`
  - Recommended: `real`
- `WECHAT_AGENT_API_TOKEN`
  - Optional. Only required if the local API is protected.

## Request contract

All API calls send:

```json
{
  "source_mode": "real"
}
```

or:

```json
{
  "record_id": "rec_xxx",
  "source_mode": "real"
}
```

Successful responses always include:

- `status`
- `stage`
- `record_id`

Failure responses always include:

- `status = failed`
- `error`

## Coze integration contract

If Coze is responsible for generation, n8n should call `/ingest-draft` instead of `/generate-draft`.

Recommended request body:

```json
{
  "record_id": "rec_xxx",
  "source_mode": "real",
  "title": "A generated title",
  "summary": "A generated summary",
  "markdown": "# Title\n\nGenerated markdown body",
  "cover_prompt": "Optional cover prompt",
  "review_status": "approved",
  "review_notes": ["Generated by Coze workflow"]
}
```

Then continue with:

1. `/create-draft`
2. `/submit-publish`
3. `/sync-status`

## Retry policy

The HTTP Request nodes are configured for:

- `maxTries = 3`
- `waitBetweenTries = 5000`

Recommended n8n handling:

- Let workflow-level failures go to an error workflow.
- Notify Feishu or email on repeated failure.
- Do not retry platform authorization failures forever.

## Workflow intent

### 01 generate draft

- Runs daily at 09:00 Asia/Shanghai
- Calls `/generate-draft`
- Moves `pending -> generated`

### 02 create draft and submit publish

- Runs daily at 09:05 Asia/Shanghai
- Calls `/create-draft`
- If successful, calls `/submit-publish`
- Moves `generated -> draft_created -> publish_submitted`

### 03 sync status

- Runs daily every 30 minutes between 09:30 and 22:30
- Calls `/sync-status`
- Moves `publishing -> published`
