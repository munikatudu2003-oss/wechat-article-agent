# Coze request and n8n field mapping examples

## Goal

This document shows the minimum data contract between:

- Coze output
- n8n HTTP Request node
- `wechat-article-agent` local API

The recommended path is:

1. n8n fetches one pending Feishu task
2. n8n sends task context into Coze
3. Coze returns structured fields
4. n8n maps those fields into `/ingest-draft`
5. n8n continues with `/create-draft`, `/submit-publish`, and `/sync-status`

## Recommended Coze output schema

Coze should return a JSON object shaped like this:

```json
{
  "title": "很多创业真相，其实都反直觉",
  "summary": "这篇文章从创业现实、人性成本和判断失误三个角度，解释为什么很多创业真相都和常识相反。",
  "markdown": "# 很多创业真相，其实都反直觉\n\n创业最容易误导人的，不是难，而是表面看起来很合理。\n\n## 1. 努力不一定带来结果\n\n很多人失败，不是因为不努力，而是因为方向错了。",
  "review_status": "approved",
  "review_notes": [
    "结构完整",
    "标题可发布",
    "无明显阻塞问题"
  ],
  "cover_prompt": "Minimalist entrepreneurship cover, bold Chinese typography, clean editorial layout"
}
```

## n8n -> Coze request body example

The payload n8n sends to Coze can include Feishu record context:

```json
{
  "record_id": "recve0BoTWMyrb",
  "title": "很多创业真相，其实都反直觉",
  "summary": "",
  "category": "创业反直觉",
  "keywords": "创业,反直觉,认知",

  "reference_material": "用户想写创业真相类内容，强调反直觉和真实感。",
  "source_url": ""
}
```

## n8n field mapping reference

If the previous node is named `Coze Output`, these expressions are recommended:

- `record_id`
  - `{{ $('Fetch Feishu Record').item.json.record_id }}`
- `source_mode`
  - `{{ $env.WECHAT_AGENT_SOURCE_MODE || 'real' }}`
- `title`
  - `{{ $('Coze Output').item.json.title }}`
- `summary`
  - `{{ $('Coze Output').item.json.summary }}`
- `markdown`
  - `{{ $('Coze Output').item.json.markdown }}`
- `review_status`
  - `{{ $('Coze Output').item.json.review_status || 'approved' }}`
- `review_notes`
  - `{{ $('Coze Output').item.json.review_notes || ['Generated by Coze'] }}`
- `cover_prompt`
  - `{{ $('Coze Output').item.json.cover_prompt || '' }}`

## Suggested n8n node order

1. `Schedule Trigger`
2. `Fetch Feishu Record`
3. `Coze HTTP Request`
4. `Ingest Draft API`
5. `Create Draft API`
6. `Submit Publish API`
7. `Sync Status API`
8. `Failure Alert`

## Safe fallback

If Coze fails:

- do not publish
- write failure into Feishu `LastError`
- notify through n8n

If Coze returns content but review is not approved:

- ingest it anyway
- keep the status generated or blocked based on your policy
- do not call `/submit-publish`
