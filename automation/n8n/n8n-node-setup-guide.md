# n8n node setup guide

This guide shows how to fill the first useful end-to-end workflow:

`Feishu pending record -> Coze generation -> /ingest-draft -> /create-draft -> /submit-publish -> /sync-status`

Use this after importing the workflow templates or when building a workflow manually.

## Environment variables

Set these in n8n before configuring nodes:

- `WECHAT_AGENT_API_BASE_URL`
  - Example: `http://127.0.0.1:8088`
- `WECHAT_AGENT_SOURCE_MODE`
  - Example: `real`
- `WECHAT_AGENT_API_TOKEN`
  - Optional

## Workflow 1: generate and ingest

### Node 1: Schedule Trigger

- Type: `Schedule Trigger`
- Cron:
  - `0 9 * * *`
- Timezone:
  - `Asia/Shanghai`

### Node 2: Fetch Feishu Record

Recommended implementation:

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - `{{ ($env.WECHAT_AGENT_API_BASE_URL || 'http://127.0.0.1:8088') + '/get-record' }}`
- Headers:
  - `Content-Type: application/json`
  - `Authorization: Bearer {{$env.WECHAT_AGENT_API_TOKEN}}`
- Body:

```json
{
  "source_mode": "real",
  "record_id": "recve0BoTWMyrb"
}
```

If you want true queue selection, replace this with a Feishu query node or your own pending-record fetcher.

### Node 3: Coze HTTP Request

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - your Coze workflow webhook URL
- Body suggestion:

```json
{
  "record_id": "{{ $('Fetch Feishu Record').item.json.record.record_id }}",
  "title": "{{ $('Fetch Feishu Record').item.json.record.title }}",
  "summary": "{{ $('Fetch Feishu Record').item.json.record.summary }}",
  "category": "{{ $('Fetch Feishu Record').item.json.record.column_type }}",
  "keywords": "{{ $('Fetch Feishu Record').item.json.record.keywords }}",
  "target_words": "{{ $('Fetch Feishu Record').item.json.record.target_words }}",
  "reference_material": "{{ $('Fetch Feishu Record').item.json.record.source_material }}",
  "source_url": "{{ $('Fetch Feishu Record').item.json.record.source_url }}"
}
```

### Node 4: Ingest Draft API

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - `{{ ($env.WECHAT_AGENT_API_BASE_URL || 'http://127.0.0.1:8088') + '/ingest-draft' }}`
- Headers:
  - `Content-Type: application/json`
  - `Authorization: Bearer {{$env.WECHAT_AGENT_API_TOKEN}}`
- Body:

```json
{
  "record_id": "{{ $('Fetch Feishu Record').item.json.record.record_id }}",
  "source_mode": "{{ $env.WECHAT_AGENT_SOURCE_MODE || 'real' }}",
  "title": "{{ $('Coze HTTP Request').item.json.title }}",
  "summary": "{{ $('Coze HTTP Request').item.json.summary }}",
  "markdown": "{{ $('Coze HTTP Request').item.json.markdown }}",
  "review_status": "{{ $('Coze HTTP Request').item.json.review_status || 'approved' }}",
  "review_notes": "{{ $('Coze HTTP Request').item.json.review_notes || ['Generated by Coze'] }}",
  "cover_prompt": "{{ $('Coze HTTP Request').item.json.cover_prompt || '' }}"
}
```

## Workflow 2: create draft and submit

### Node 1: Create Draft API

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - `{{ ($env.WECHAT_AGENT_API_BASE_URL || 'http://127.0.0.1:8088') + '/create-draft' }}`
- Body:

```json
{
  "record_id": "{{ $('Fetch Feishu Record').item.json.record.record_id }}",
  "source_mode": "{{ $env.WECHAT_AGENT_SOURCE_MODE || 'real' }}"
}
```

### Node 2: IF Draft Created

- Type: `IF`
- Condition:
  - `{{ $json.status }} == ok`

### Node 3: Submit Publish API

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - `{{ ($env.WECHAT_AGENT_API_BASE_URL || 'http://127.0.0.1:8088') + '/submit-publish' }}`
- Body:

```json
{
  "record_id": "{{ $('Fetch Feishu Record').item.json.record.record_id }}",
  "source_mode": "{{ $env.WECHAT_AGENT_SOURCE_MODE || 'real' }}"
}
```

## Workflow 3: sync status

### Node 1: Sync Status API

- Type: `HTTP Request`
- Method: `POST`
- URL:
  - `{{ ($env.WECHAT_AGENT_API_BASE_URL || 'http://127.0.0.1:8088') + '/sync-status' }}`
- Body:

```json
{
  "record_id": "{{ $('Fetch Feishu Record').item.json.record.record_id }}",
  "source_mode": "{{ $env.WECHAT_AGENT_SOURCE_MODE || 'real' }}"
}
```

### Node 2: IF Published

- Type: `IF`
- Condition:
  - `{{ $json.stage }} == published`

## Recommended failure handling

For every HTTP node:

- enable retry
- set max tries to `3`
- wait `5000ms` between tries

For workflow errors:

- route failures into Feishu or email alerts
- include:
  - `record_id`
  - `status`
  - `stage`
  - `error`

## Notes

- Use API for anything that has a stable API path.
- Only call Yingdao when the needed step cannot be completed by API.
- Keep WeChat publish side effects in `wechat-article-agent`, not in Coze.
